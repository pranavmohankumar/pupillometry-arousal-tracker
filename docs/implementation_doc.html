Project #8 Specification

Pupillometry-Based Cognitive Load & Arousal Tracker

Target Industry Profile: NexStem, Tobii, Affective Computing Startups

1. System Architecture & Concept

OpenCV pupil extraction pipeline, Continuous Wavelet Transform (CWT) feature analyzer, and Ridge Regression arousal estimator.

2. Synthetic Bio-Data Engineering Strategy

Synthetic video frame sequences of eye pupil dilations/constrictions under variable illumination and cognitive tasks.

3. Low-End LLM Prompt & Module Blueprint

  • Module 1: Eye Video Frame Generator: Generate synthetic pupil video frames with dynamic diameter changes and glare artifacts.
  • Module 2: Pupil Diameter Extractor: Implement OpenCV ellipse fitting algorithm to measure real-time pupil contour area.
  • Module 3: CWT & Arousal Estimator: Extract low-frequency pupil oscillations via Wavelet transform to predict arousal score.

4. Core Technical Starter Skeleton

import numpy as np
from scipy.signal import cwt, morlet

def analyze_pupil_oscillations(pupil_diameters, fs=30):
    widths = np.arange(1, 31)
    cwt_matrix = cwt(pupil_diameters, morlet, widths)
    low_freq_power = np.mean(np.abs(cwt_matrix[10:25, :]), axis=0)
    return low_freq_power
